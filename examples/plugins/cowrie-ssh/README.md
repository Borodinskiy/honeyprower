# Cowrie SSH Honeypot — пример своей ловушки

SSH-приманка в стиле [Cowrie](https://github.com/cowrie/cowrie) на Paramiko для
HoneyForge. Загрузите каталог архивом на вкладке «Свои ловушки» — появится класс
`plugin:cowrie-ssh`.

```bash
tar -czf cowrie-ssh.tar.gz -C examples/plugins cowrie-ssh
```

Ставить на серверы ничего не нужно. При развёртывании центр сам:

- ставит `python3` менеджером пакетов сервера, если его нет (`packages`);
- скачивает paramiko со всеми зависимостями под Python, архитектуру и libc
  этого сервера и привозит их в каталог ловушки (`pip`) — серверу не нужны
  ни pip, ни доступ в интернет;
- проверяет, что модуль импортируется (`python_modules`).

## Что умеет

- Настоящий SSH: обмен ключами, ключи хоста Ed25519, ECDSA и RSA (хранятся в
  каталоге данных ловушки), вход по паролю — все режимы проверки из параметров;
  попытки входа по ключу записываются с отпечатком.
- Оболочка: `exec` (`ssh host 'cmd'`) и интерактивный вход, в том числе оба в
  одном соединении; цепочки `;`, `&&`, `||`, конвейеры `|`, перенаправления
  `>`, `>>`, `<`, кавычки, переменные `$VAR`.
- Своя файловая система на сессию: `cd`, `ls -la`, `cat`, `mkdir -p`, `touch`,
  `rm -rf`, `cp`, `mv`, `chmod`, `head`, `tail`, `grep`, `wc`; права root и
  обычного пользователя различаются (`/etc/shadow`, `/root`).
- Разведка: `uname`, `id`, `whoami`, `ps`, `free`, `df`, `ip`, `ifconfig`,
  `w`, `uptime`, `/proc/cpuinfo`, `/etc/os-release` и другие.
- Загрузки: `wget`, `curl` (в файл и в конвейер `curl … | sh`), `base64 -d`,
  `echo … > файл` — событие `payload` с путём, URL, SHA-256, размером и началом
  содержимого. Скрипты, переданные в `sh`/`bash` или запущенные как `./x.sh`,
  выполняются построчно, каждая строка — событие `command`.
- С параметром «Скачивать файлы атакующего» wget/curl действительно скачивают
  файл — только с публичных адресов, с ограничением размера — и сохраняют его в
  `downloads/<sha256>` каталога данных ловушки.

## События

| Тип | Когда |
|---|---|
| `connect`, `disconnect` | подключение; при отключении — длительность и число команд |
| `auth` | попытка входа: логин, пароль или отпечаток ключа, успех |
| `command` | каждая команда: `data.line`, `data.mode` — `interactive`, `exec`, `script` |
| `payload` | записанный или скачанный файл |

## Тесты

```bash
python3 -m unittest discover -s examples/plugins/cowrie-ssh
```
