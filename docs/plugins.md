# Свои ловушки

Свой проект — например, эмулятор сервиса на Python или Go — можно загрузить
в центр и разворачивать на хостах наравне со встроенными классами. Проект
становится классом ловушки `plugin:<name>`: его выбирают в форме ловушки,
параметры рисуются по схеме из манифеста, события попадают в дашборд и на
вкладку «События».

Готовые шаблоны скачиваются на вкладке «Свои ловушки» (или
`GET /api/plugin-templates/service`, `.../stdio`). Их можно загрузить обратно
без правок — так удобно проверить, что всё работает.

## Как это устроено

```
центр ──SSH──▶ хост: /opt/honeyforge/plugins/<name>-<sha12>/   ← файлы проекта
                     /usr/local/bin/honeyforge-agent            ← запускает проект
                     /etc/honeyforge/config.json                ← как запускать, параметры
проект ──строки JSON──▶ агент ──шифрованные события──▶ центр
```

1. Архив проверяется при загрузке (пути, ссылки, размер, манифест) и
   пересобирается в tar.gz. Одинаковое содержимое даёт одинаковый SHA-256.
2. При развёртывании хоста центр проверяет программы из `requires`, кладёт
   архив в отдельный каталог на версию и только потом обновляет агента.
   Версия, которая уже стоит, повторно не загружается.
3. Агент запускает программу от пользователя `nobody`, перезапускает её при
   падении (пауза 1 → 2 → … → 60 с) и шлёт её события в центр под токеном
   ловушки.
4. Если программа упала в первые 2 секунды, агент не стартует: деплой
   показывает последние строки её вывода и откатывает хост на прежнюю
   рабочую версию. Старые версии удаляются только после успешного запуска.

## Архив

`.zip` или `.tar.gz`, до 32 МБ (до 128 МБ после распаковки). В корне — или в
единственной папке архива — файл `honeyforge-plugin.json`. Допустимы обычные
файлы, каталоги и относительные ссылки внутри проекта. Файл, на который
указывает `command`, станет исполняемым.

## Манифест `honeyforge-plugin.json`

```json
{
  "name": "my-ftp",
  "title": "Мой FTP",
  "description": "Что делает ловушка",
  "version": "1.0.0",
  "mode": "service",
  "transport": "tcp",
  "command": ["python3", "server.py"],
  "default_port": 2121,
  "requires": ["python3"],
  "params": [
    {"key": "banner", "title": "Баннер", "type": "string", "default": "220 ready"},
    {"key": "level", "title": "Уровень", "type": "enum", "default": "low",
     "options": [{"value": "low", "label": "Низкий"}, {"value": "high", "label": "Высокий"}]}
  ]
}
```

| Поле | |
|---|---|
| `name` | `[a-z0-9][a-z0-9_-]{0,39}`; класс ловушки — `plugin:<name>`. Загрузка с тем же именем — новая версия. |
| `title`, `description`, `version` | для списка и формы |
| `mode` | `service` (по умолчанию) или `stdio`, см. ниже |
| `transport` | `tcp` (по умолчанию) или `udp`; `stdio` — только `tcp` |
| `command` | argv. Аргумент с `/` и без ведущего `/` — путь внутри архива (`./run.sh`, `bin/server`), без `/` — программа из `PATH` |
| `default_port` | порт новой ловушки по умолчанию |
| `requires` | программы, которые должны быть на хосте (`python3`, `node`, …) |
| `params` | поля формы — тот же формат, что у встроенных классов: `string`, `text`, `int`, `number`, `bool`, `enum`, `list`; `default`, `min`/`max`, `help`, `advanced`, `regex`, `showIf` |
| `default_params` | значения по умолчанию сверх `default` полей |

Новая версия не принимается, если параметры уже созданных на ней ловушек не
подходят к новой схеме: центр перечислит такие ловушки.

## Режим `service`

Программа сама слушает порт. Подходит для готового сервера.

- Слушать на `HF_BIND`:`HF_PORT`. Агент проверяет, что порт свободен, до
  запуска программы.
- События — строки JSON в stdout или stderr.

## Режим `stdio`

Порт слушает агент. На каждое подключение он запускает программу:

- stdin — что прислал клиент, stdout — что клиент увидит;
- события — только в stderr (stdout занят клиентом);
- адрес клиента и сессию агент подставляет в события сам, они же есть в
  `HF_SRC_IP`, `HF_SRC_PORT`, `HF_DST_PORT`, `HF_SESSION`;
- подключение, отключение и начало ввода клиента агент записывает сам;
- программа завершилась — соединение закрывается; клиент ушёл или молчит
  дольше `idle_timeout` — программа убивается вместе с её потомками;
- одновременно — не больше `max_clients` процессов (оба параметра
  добавляются в форму автоматически).

## События

Одна строка — одно событие: JSON-объект с полем `type`. Остальной вывод
программы попадает в журнал агента (`journalctl -u honeyforge-agent`).

```json
{"type": "auth", "src_ip": "203.0.113.5", "src_port": 51234, "username": "root", "password": "123456", "data": {"attempt": 1}}
```

| Поле | |
|---|---|
| `type` | `connect`, `disconnect`, `data`, `auth`, `command`, `request`, `handshake`, `scan`, `token`, `error`; иной тип станет `data` с `data.custom_type` |
| `src_ip`, `src_port` | адрес клиента; в `stdio` можно не указывать |
| `dst_port` | по умолчанию — порт ловушки |
| `session` | по умолчанию в `service` выводится из адреса и порта клиента: события одного соединения — одна сессия |
| `username`, `password` | до 256 символов |
| `data` | объект с подробностями (до 16 КБ); на вкладке «События» видны `data.line` у `command`, `method`/`path` у `request` |

Не больше 100 событий в секунду в среднем (всплеск до 200): лишние
отбрасываются, агент раз в минуту сообщает, сколько.

## Окружение программы

| Переменная | |
|---|---|
| `HF_MODE` | `service` или `stdio` |
| `HF_BIND`, `HF_PORT` | где слушать (в `stdio` — где слушает агент) |
| `HF_PARAMS` | параметры ловушки из центра, JSON |
| `HF_TRAP_NAME` | имя ловушки |
| `HF_PLUGIN_DIR` | каталог проекта (только чтение, он же рабочий каталог) |
| `HF_DATA_DIR` | каталог для записи, сохраняется между перезапусками |
| `PYTHONUNBUFFERED=1` | чтобы события Python не задерживались в буфере |

## Без хоста

Для ловушки без хоста после создания можно скачать zip («Скачать .zip»): `config.json`,
каталог `plugins/<name>-<sha12>/` с проектом и `RUN.txt`. Положите рядом
бинарник агента и запустите `./honeyforge-agent config.json` — путь к проекту
считается от каталога конфига.

## API

| | |
|---|---|
| `GET /api/plugins` | список с ловушками, которые используют каждый проект |
| `POST /api/plugins` | загрузка: поле `archive` формы multipart или тело запроса |
| `GET /api/plugins/{name}` | один проект |
| `DELETE /api/plugins/{name}` | удаление; 409, если есть ловушки |
| `GET /api/plugins/{name}/archive` | архив в том виде, в каком он уезжает на хосты |
| `GET /api/plugin-templates/{service\|stdio}` | шаблон проекта |

## Безопасность

Загруженный код выполняется на хостах. Его может загрузить любой оператор
центра — так же, как любой оператор может развернуть агента на хосте с
сохранённым SSH-доступом. Если регистрация открыта (`ALLOW_REGISTRATION`),
закройте её. На хосте программа работает от `nobody` с правом занимать
порты ниже 1024 — как и сам агент.
