Ловушка готова к запуску

Конфиг едет вместе с бинарником агента. Из центра к агенту ничего не идёт: чтобы изменить ловушку — обновите её здесь и перезапустите агент с новым конфигом.

  1. Соберите агент один раз: cd agent && cargo build --release
  2. Скачайте конфиг и положите рядом с бинарником.
  3. Запустите: ./honeyforge-agent config.json
