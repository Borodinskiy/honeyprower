Ловушка создана

Ловушка не привязана к хосту. Запустите агента вручную или привяжите ловушку к хосту, чтобы центр сам разворачивал её по SSH.

  1. Соберите агент один раз: cd agent && cargo build --release
  2. Скачайте конфиг и положите рядом с бинарником.
  3. Запустите: ./honeyforge-agent config.json

Новый хост

Доступ по SSH центр хранит зашифрованным и в браузер не возвращает. По нему он ставит, обновляет и снимает агента хоста.
