Свои ловушки

Шаблон: service Шаблон: stdio

Свой проект становится классом ловушки: его можно выбрать при создании ловушки и развернуть на любом хосте. Агент запускает программу, следит за ней и пересылает её события в центр.

Как подготовить проект

Архив .zip или .tar.gz с файлом honeyforge-plugin.json в корне (или в единственной папке архива). Проще всего скачать шаблон и поменять в нём код.

{
  "name": "my-ftp",
  "title": "Мой FTP",
  "version": "1.0.0",
  "mode": "service",
  "command": ["python3", "server.py"],
  "default_port": 2121,
  "requires": ["python3"],
  "params": [
    {"key": "banner", "title": "Баннер", "type": "string", "default": "220 ready"}
  ]
}
nameлатиница, цифры, - и _; класс ловушки будет plugin:name
modeservice — программа сама слушает порт из HF_PORT на адресе HF_BIND. stdio — порт слушает агент и на каждое подключение запускает программу: stdin и stdout — это клиент.
commandкак запустить программу; путь с / считается внутри архива (./run.sh)
requiresпрограммы, которые должны быть на хосте; деплой проверит их до установки
paramsполя формы ловушки, как у встроенных классов: string, text, int, number, bool, enum, list. Значения приходят программе в HF_PARAMS (JSON).

Событие — одна строка JSON с полем type. В режиме service её можно печатать в stdout или stderr, в режиме stdio — только в stderr. Остальной вывод попадает в журнал агента.

{"type": "auth", "src_ip": "203.0.113.5", "src_port": 51234, "username": "root", "password": "123456"}
{"type": "command", "data": {"line": "uname -a"}}

Типы: connect, disconnect, data, auth, command, request, handshake, scan, token, error. В режиме stdio адрес клиента и сессию агент подставит сам. Каталог для записи — HF_DATA_DIR; программа работает от пользователя nobody.

Ловушка создана

Ловушка не привязана к хосту. Запустите агента вручную или привяжите ловушку к хосту, чтобы центр сам разворачивал её по SSH.

  1. Соберите агент один раз: cd agent && cargo build --release
  2. Скачайте конфиг и положите рядом с бинарником.
  3. Запустите: ./honeyforge-agent config.json

Новый хост

Доступ по SSH центр хранит зашифрованным и в браузер не возвращает. По нему он ставит, обновляет и снимает агента хоста.
